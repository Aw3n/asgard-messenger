Features

Everything you need, nothing you don't

Asgard delivers a complete messaging experience without relying on any central server. Every feature runs directly between peers using the Hyperswarm DHT and Hypercore protocol.

💬

Secure Messaging

Send text messages with Ed25519 digital signatures. Messages are cryptographically signed and verified, ensuring authenticity. Full markdown support with code blocks, links, and formatting.

Ed25519 Signed
✓✓

Delivery & Read Receipts

Know exactly when your message is delivered and read. Per-recipient tracking in group chats with automatic retry for offline peers. Unified receipt protocol with hierarchical status.

Per-recipient tracking
🎙️

Voice Messages

Record and send voice messages with real-time audio compression via Web Audio API. Adaptive silence detection saves bandwidth. Playback with waveform visualization.

Web Audio API
📞

Audio & Video Calls

Crystal-clear audio and video calls over P2P. Adaptive jitter buffer, silence detection, and dynamic frame rate adjustment based on network quality. No WebRTC, no STUN/TURN servers.

WebCodecs + Protomux
👥

Group Calls (Mesh)

Full mesh topology for group calls — each participant connects directly to all others. Adaptive video quality based on participant count. Graceful join/leave without dropping the call.

Mesh Topology
📁

File Transfer

Send files of any size with a dedicated Protomux channel. Sliding window pipeline for parallel chunk delivery. Multicast to group members with per-peer progress tracking.

Dedicated Channel
🏠

Groups & Channels

Create groups with multiple channels, roles, and permissions. Owner, admin, and member roles. Hyperbee CAS (Compare-And-Swap) prevents concurrent modification race conditions.

Hyperbee CAS
🟢

Presence & Status

Real-time presence with online, away, DND, and invisible modes. Custom status messages. 30-second heartbeat with 60-second timeout. Group presence with per-member visibility.

Heartbeat 30s
🔍

Contact Discovery

Find peers via Hyperswarm DHT topics derived from SHA-256 hashes. Direct peer connection via Noise public key with holepunching through NAT. QR code sharing for easy invites.

Hyperswarm DHT
🪪

DHT Profile

Publish your profile (display name, avatar, status) to the HyperDHT using mutable records. Peers can fetch your profile even when you're offline. Immutable records for permanent data.

Mutable Records
📂

File Management

Download history, favorites, share links, and trash management. Blob storage with Hyperblobs-compatible block sizing. Export and import functionality for data portability.

Hyperblobs
🔎

Universal Search

Search messages across all conversations with Hyperbee range scans. Fast pagination with reverse streaming. Search contacts, groups, and file attachments in real-time.

Hyperbee Range Scan
🛡️

Blocked Peers

Block unwanted contacts with HyperDHT firewall integration. Blocked peers cannot connect or send messages. Full ban/unban control with persistent storage.

DHT Firewall
✏️

Message Editing

Edit sent messages with full edit history. Forward messages to other conversations. Delete messages with hard delete option. React with emojis — multiple reactions per message.

Edit History
📊

Network Diagnostics

Real-time bandwidth monitoring with sliding window averaging. Peer latency measurement via ping/pong RTT. Peer quality scoring. Protomux channel diagnostics with cork/uncork.

RTT + Bandwidth
🎨

Dynamic Theming

Multiple color themes with smooth transitions. No flash of unstyled content on load. Glassmorphism UI with backdrop blur. Fully responsive layout for any screen size.

Glassmorphism
Privacy First

Zero servers. Zero surveillance.

Asgard doesn't just promise privacy — it's built into the architecture. There are no servers to compromise, no databases to breach, no metadata to collect. Your messages travel directly between devices.

✓ No central servers — pure peer-to-peer via Hyperswarm
✓ No metadata stored — data lives only on your device via Hyperbee
✓ No phone number or email required — Ed25519 identity only
✓ No tracking, no analytics, no telemetry
✓ 24-word seed phrase backup — own your identity forever
🛡️

Your identity is a cryptographic key pair generated locally. No registration, no verification, no phone number.

🔐 Ed25519 — Digital signatures for message authenticity
🔑 Noise Protocol — Encrypted transport via Hyperswarm
🌐 Hyperswarm DHT — Distributed peer discovery
📦 Hypercore — Append-only replicated feeds
🐝 Hyperbee — Encrypted local key-value storage
